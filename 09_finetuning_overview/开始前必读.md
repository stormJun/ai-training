# 🎯 MASSIVE 中文意图分类微调任务

## 📋 任务目标

**核心任务**: 使用 MASSIVE 中文意图分类数据集，微调一个大语言模型，使其能够准确识别用户语句的意图。

### 具体目标

1. **训练任务**:
   - 使用 11,514 条中文意图分类样本训练模型
   - 60 种意图类别（闹钟、音乐、日历、天气等）
   - 达到 85%+ 准确率

2. **应用场景**:
   - 智能助手意图识别
   - 语音交互系统
   - 对话机器人
   - IoT 设备控制

3. **预期成果**:
   - 微调后的模型 checkpoint
   - 合并后的完整模型
   - 评估报告（准确率、各意图表现）
   - 可部署的推理代码

## 🎮 三种运行方式

安装完依赖后，你可以选择以下任一方式开始微调：

### **方式 1: 一键启动脚本 (最简单)**

```bash
cd 09_finetuning_overview
./quick_start_massive.sh
```

**特点**:
- ✅ 自动检查数据
- ✅ 交互式配置
- ✅ 引导式操作
- 推荐给新手

---

### **方式 2: Web 界面 (最直观)**

```bash
cd 09_finetuning_overview

# 启动 Web 界面
python3 -m local_ft.server

# 在浏览器访问
# http://localhost:7866
```

**操作流程**:

1. **数据上传** (http://localhost:7866/data_upload)
   - 上传 `train_converted.jsonl`
   - 数据集名称: `massive_zh_intent`
   - 预览数据

2. **模型微调** (http://localhost:7866/fine_tune)
   - 基础模型: `Qwen/Qwen2.5-1.5B-Instruct`
   - 训练类型: `lora`
   - 数据集: `custom:massive_zh_intent`
   - 训练轮数: `3`
   - 批次大小: `8`
   - 学习率: `1e-4`
   - LoRA Rank: `8`
   - 点击 **开始训练**

3. **监控训练**
   - 实时查看 Loss 曲线
   - 查看日志输出
   - 等待训练完成（约 1 小时）

4. **权重合并** (http://localhost:7866/model_merge)
   - 选择 checkpoint
   - 点击 **开始合并**

5. **模型评估**
   ```bash
   python3 evaluate_massive_model.py \
     --model merged_model \
     --test_file amazon_massive_intent_zh-CN/test_converted.jsonl
   ```

**特点**:
- ✅ 可视化界面
- ✅ 实时监控
- ✅ 无需命令行
- 推荐给大多数用户

---

### **方式 3: 命令行 (最灵活)**

```bash
cd 09_finetuning_overview

# 直接运行 swift 命令
swift sft \
  --model Qwen/Qwen2.5-1.5B-Instruct \
  --train_type lora \
  --dataset amazon_massive_intent_zh-CN/train_converted.jsonl \
  --num_train_epochs 3 \
  --per_device_train_batch_size 8 \
  --learning_rate 1e-4 \
  --lora_rank 8 \
  --lora_alpha 16 \
  --target_modules q_proj k_proj v_proj o_proj \
  --gradient_accumulation_steps 4 \
  --eval_steps 100 \
  --save_steps 500 \
  --save_total_limit 2 \
  --logging_steps 10 \
  --max_length 512 \
  --output_dir output/massive_zh_$(date +%Y%m%d-%H%M%S)
```

**训练完成后**:

```bash
# 1. 合并权重
swift export \
  --ckpt_dir output/massive_zh_xxx/checkpoint-1000 \
  --merge_lora true \
  --output_dir merged_model

# 2. 评估模型
python3 evaluate_massive_model.py \
  --model merged_model \
  --test_file amazon_massive_intent_zh-CN/test_converted.jsonl

# 3. 测试推理
python3 -c "
from transformers import AutoModelForCausalLM, AutoTokenizer

model = AutoModelForCausalLM.from_pretrained('merged_model')
tokenizer = AutoTokenizer.from_pretrained('merged_model')

text = '明天早上七点叫醒我'
prompt = f'请识别以下用户语句的意图分类\\n{text}'

inputs = tokenizer(prompt, return_tensors='pt')
outputs = model.generate(**inputs, max_length=100)
result = tokenizer.decode(outputs[0], skip_special_tokens=True)

print('输入:', text)
print('输出:', result)
"
```

**特点**:
- ✅ 完全控制
- ✅ 自定义参数
- ✅ 脚本自动化
- 推荐给高级用户

## 🐛 可能遇到的问题

### 问题 1: 依赖安装失败

**Intel Mac 用户**:
```bash
# 如果 uv sync 报错 torch 不兼容
# 修改 pyproject.toml 中的 torch 版本为 2.2.2
torch = "==2.2.2"

# 然后重新运行
uv sync
```

### 问题 2: 显存不足

```bash
# 减小批次大小
--per_device_train_batch_size 4
--gradient_accumulation_steps 8

# 或使用更小的模型
--model Qwen/Qwen2.5-0.5B-Instruct
```

### 问题 3: 模型下载慢

```bash
# 设置 HuggingFace 镜像
export HF_ENDPOINT=https://hf-mirror.com

# 或使用 ModelScope
--model_id_or_path qwen/Qwen2.5-1.5B-Instruct
```

### 问题 4: swift 命令找不到

```bash
# 确认 ms-swift 安装
pip show ms-swift

# 重新安装
pip install ms-swift -U
```
