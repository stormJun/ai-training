                        实际案例对比

场景：下雨天自动关窗

【米家App】
触发：天气 = 下雨
动作：关闭窗户

配置时间：30秒
优点：简单直接
缺点：无法处理边缘情况


【Home Assistant】
```yaml
automation:
  - trigger:
      - platform: state
        entity_id: sensor.weather
        to: 'rainy'
    condition:
      - condition: state
        entity_id: cover.window
        state: 'open'    # 只有开着才关
      - condition: sun
        after: sunrise
        before: sunset   # 只在白天执行
    action:
      - service: notify.mobile_app
        data:
          message: "下雨了，正在关窗"
      - service: cover.close_cover
        data:
          speed: slow    # 慢速关闭，避免夹东西
      - delay: {seconds: 5}
      - choose:          # 5秒后检查
          - conditions:
              - condition: state
                entity_id: cover.window
                state: 'open'
            sequence:
              - service: notify.mobile_app
                data:
                  message: "警告：窗户未完全关闭"
```

配置时间：10分钟
优点：考虑所有边缘情况、有通知、有错误处理
缺点：需要技术知识
