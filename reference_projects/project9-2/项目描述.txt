实践九（生产版）：高并发流式 Agent 服务（在 9_1 基础上工程化）

输入输出定义：
- 输入：同 9_1（POST /chat + WebSocket /ws/{client_id}）
- 输出：同 9_1 的事件流，新增缓存命中快路径与重试容错
- 扩展项：Redis 缓存 / 固定窗口限流 / tenacity 指数退避重试 /
  structlog 结构化日志 / Request-ID 链路追踪 / 全局异常处理 / 健康检查 / 分层架构

关键挑战：
- 如何在不阻塞 HTTP 的前提下叠加限流、缓存、重试等生产关注点？
- 多个横切关注点（日志/限流/缓存/重试）如何与 Agent 执行流解耦编排？
- 缓存命中与正常流式两条路径如何统一回推？
- 重试带来的长耗时如何不拖垮连接？

说明：
- 依赖 Redis（限流与缓存共用），启动前需先运行 Redis。
- 本项目暂未提供 requirements.txt 与 test_client.py（见文档"已知缺口"）。
- 仍是单进程教学骨架，分布式/持久化缺口见文档"生产化缺口"。
