# Ray Serve 流式服务

本主题提供 Ray Serve 与流式响应相关示例。

## 内容

- `ray_examples/`
  - Ray 示例集合
- `ray_examples/1-通过 HTTP 调用部署.py`
  - HTTP 调用示例
- `ray_examples/4-流式响应.py`
  - 流式响应示例
- `ray_examples/5-客户端断开连接时终止流.py`
  - 连接中断处理示例

## 开始方式

- 从 `ray_examples/` 中按编号阅读和运行示例
- 环境准备可参考 `../../40_fastapi_llm_serving/README.md`
