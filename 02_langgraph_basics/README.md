# LangGraph Learning Path

This topic is organized as a staged learning path for LangGraph engineering:

1. `01_intro/`
   Minimal examples and the core LangGraph mental model.
2. `02_workflows/`
   Workflow orchestration, HITL, memory, RAG, snapshots, and Studio.
3. `03_service_apps/`
   Turning graphs into local services and structured app projects.
4. `04_demo_project/`
   A complete Host/Subagent demo project.
5. `05_multi_agent/`
   LangGraph multi-agent collaboration examples.
6. `06_protocols_and_integrations/`
   MCP basics, MCP + LangGraph, and A2A + LangGraph.
7. `07_deep_dive_notes/`
   Architecture notes, source-level analysis, and extension reading.

## Directory Rules

- Tutorial stages use numbered folders to reflect learning order.
- Runnable projects keep their internal `src/`, `tests/`, and packaging structure.
- Local runtime artifacts such as `.venv/`, `.pytest_cache/`, `.env`, and `__pycache__/` should not be kept in this topic.
