# LangGraph 多智能体

本主题展示基于 LangGraph 的多智能体示例。

## 内容

- `p13-Langgraph-MAS.ipynb`
  - LangGraph 多智能体 Notebook
- `p13-Langgraph-MAS.md`
  - Notebook 转写后的 Markdown 版本
- `p13-Langgraph-MAS.py`
  - Notebook 整理后的 Python 脚本版本

## 开始方式

- 可直接打开 Notebook 或 Markdown 学习
- Python 脚本可通过 `python p13-Langgraph-MAS.py` 运行
- 环境准备可参考 `../../../../08_multi_agent_frameworks/01_autogen_two_agent_chat/README.md`
