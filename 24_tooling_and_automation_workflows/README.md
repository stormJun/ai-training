# 工具化与自动化工作流专题

本父目录合并了原来的 `24_code_assistant_workflow/`、`25_vllm_wrapper_demo/` 和 `26_rpa_and_ai_workflow/`，目的是减少仓库顶层目录数量，同时保留各主题原本的工作区结构。

## 子目录

- `24_code_assistant_workflow/`
  - 代码助手工作流与子项目说明
- `25_vllm_wrapper_demo/`
  - vLLM wrapper 示例与配置脚本
- `26_rpa_and_ai_workflow/`
  - RPA 与 AI 工作流集成案例与说明文档

## 建议学习顺序

1. 先看 `24_code_assistant_workflow/`
2. 再看 `25_vllm_wrapper_demo/`
3. 最后进入 `26_rpa_and_ai_workflow/`

## 说明

- 该父目录只做聚合，不拆分各子主题内部结构。
- 子目录里的命令默认以仓库根目录或各自子目录为起点，具体以子目录 README 为准。
