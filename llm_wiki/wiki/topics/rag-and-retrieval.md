# RAG 与检索

## 仓库位置

- `04_rag_and_retrieval/`

## 在课程中的角色

本主题是训练营中“让模型基于外部资料回答问题”的核心模块，承接 LlamaIndex 基础，并引出检索评测、GraphRAG、本地 RAG 工程和 QAnything 案例。

## 学习者应掌握的内容

- 如何把资料接入检索系统
- 如何理解传统 RAG 的检索、拼接、生成流程
- 如何用 Ragas 等工具评估检索质量
- GraphRAG 与传统 RAG 的差异
- 本地 RAG 项目和 QAnything 案例的工程入口

## 前置知识

- LLM API 基础
- LangChain 或 LlamaIndex 基础
- Prompt 与输出解析基础
