# 输出解析与链式调用

本主题围绕输出解析、自定义解释器和基础链路示例展开。

## 内容

- `first_chat_chain.md` / `first_chat_chain.py`
  - 对话链入门
- `custom_llm_interface.md` / `custom_llm_interface.py`
  - 自定义大模型接口说明
- `custom_output_parser.md` / `custom_output_parser.py`
  - 自定义输出解析示例
- `chain_and_runnable_guide.md` / `chain_and_runnable_guide.py`
  - 链、Runnable、LCEL 语法解析
- `dashscope_examples/`
  - 相关补充材料

## 开始方式

- 优先阅读 `.md` 理解概念
- 再运行对应 `.py` 看示例代码
- 环境准备可参考 `../README.md`
