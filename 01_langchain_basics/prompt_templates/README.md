# Prompt 模板

本主题收纳 Prompt 模板、基础模板文件以及自定义模板工程化示例。

## 内容

- `prompt_template_overview.md`
  - Prompt 模板总览说明
- `prompt_template_overview.py`
  - Prompt 模板示例导航脚本
- `prompt.txt`
  - 模板文本示例
- `examples/`
  - 相关补充文件
  - 包含自定义模板、测试脚本、扩展脚本和配置文件
- `pyproject.toml`
  - 本主题依赖定义

## 开始方式

- 在本目录执行 `uv sync --locked`
- 优先阅读 `.md`
- 再运行 `.py` 或查看 `examples/` 下的脚本
