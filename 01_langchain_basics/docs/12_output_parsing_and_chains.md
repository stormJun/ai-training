# 输出解析与链式调用

本主题围绕输出解析、自定义解释器和基础链路示例展开。

## 内容

- `13_first_chat_chain.md` / `13_first_chat_chain.py`
  - 对话链入门
- `14_custom_llm_interface.md` / `14_custom_llm_interface.py`
  - 自定义大模型接口说明
- `15_custom_output_parser.md` / `15_custom_output_parser.py`
  - 自定义输出解析示例
- `16_chain_and_runnable.md` / `16_chain_and_runnable.py`
  - 链、Runnable、LCEL 语法解析
- `19_dashscope_demo.py` / `20_dashscope_intent_pipeline.py`
  - DashScope 意图识别补充材料
- `20_dashscope_intent_config.json`
  - DashScope 意图识别示例配置

## 开始方式

- 优先阅读 `.md` 理解概念
- 再运行对应 `.py` 看示例代码
- 环境准备可参考 `../README.md`
