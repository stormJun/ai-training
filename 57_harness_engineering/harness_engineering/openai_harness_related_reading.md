# OpenAI Harness 与 Codex 工程化相关阅读

如果你说的是“OpenAI 官方、和 Harness / Codex / agent-first 工程化最相关”的经典读物，我会按这个顺序读：

## 1. Harness engineering: leveraging Codex in an agent-first world

核心原文，最直接。讲执行环境、`AGENTS.md`、progress files、结构测试、可观测性怎么服务 agent。

- 发布：2026 年 2 月 11 日
- 链接：https://openai.com/index/harness-engineering/

## 2. How OpenAI uses Codex

更偏实践手册，讲 OpenAI 内部怎么用 Codex 做代码理解、迁移、提测、保持 flow。和 Harness 那篇非常互补。

- 链接：https://openai.com/business/guides-and-resources/how-openai-uses-codex/

## 3. Introducing Codex

适合补“Codex 这个云端工程 agent 的产品形态和定位”背景。

- 发布：2025 年 5 月 16 日
- 链接：https://openai.com/index/introducing-codex/

## 4. A practical guide to building agents

不是专讲 Codex，但对理解 harness 背后的 loop、tools、guardrails、handoff 很关键。

- 链接：https://openai.com/business/guides-and-resources/a-practical-guide-to-building-ai-agents/

## 5. Addendum to o3 and o4-mini system card: Codex

如果你想看更技术和安全侧的“Codex 是怎么被定义的”，这篇值得读。

- 发布：2025 年 5 月 16 日
- 链接：https://cdn.openai.com/pdf/8df7697b-c1b2-4222-be00-1fd3298f351d/codex_system_card.pdf

## 6. Codex is now generally available

更偏规模化落地和团队使用方式，能看到 Codex 从 preview 到工程团队日常工具的演进。

- 链接：https://openai.com/index/codex-now-generally-available/

## 如果只读三篇

- Harness engineering
- How OpenAI uses Codex
- A practical guide to building agents
