# 第一部分：量化技术深度剖析

## 1.1 量化理论基础

### 1.1.1 量化的数学定义

**量化 (Quantization)**: 将连续值映射到离散值的过程

```
数学形式:
    Q: ℝ → ℤ
    Q(x) = round(x / s) - z

其中:
    x ∈ ℝ      : 实数域的浮点权重
    s ∈ ℝ⁺     : 缩放因子 (scale)
    z ∈ ℤ      : 零点偏移 (zero-point)
    Q(x) ∈ ℤ   : 量化后的整数

反量化 (Dequantization):
    x' = s * (Q(x) + z)
```

---

### 1.1.2 对称量化 vs 非对称量化

#### 对称量化 (Symmetric Quantization)

**特点**: 零点固定为 0，量化范围对称分布

```python
# 数学公式
s = max(|x_max|, |x_min|) / (2^(b-1) - 1)
z = 0
Q(x) = round(x / s)

# INT8 对称量化: [-127, 127]
# 示例
x = [-2.5, -1.0, 0.0, 1.5, 3.0]
x_max = 3.0, x_min = -2.5

s = 3.0 / 127 = 0.0236
Q(x) = [-106, -42, 0, 64, 127]
```

**优点**:
- 计算简单（省去零点运算）
- 硬件实现高效

**缺点**:
- 当数据分布不对称时，量化范围利用率低

**适用场景**: 权重量化（通常对称分布）

---

#### 非对称量化 (Asymmetric Quantization)

**特点**: 零点可变，充分利用量化范围

```python
# 数学公式
s = (x_max - x_min) / (2^b - 1)
z = round(-x_min / s)
Q(x) = round(x / s) + z

# INT8 非对称量化: [0, 255]
# 示例
x = [0.5, 1.2, 2.8, 4.5, 5.0]
x_max = 5.0, x_min = 0.5

s = (5.0 - 0.5) / 255 = 0.0176
z = -0.5 / 0.0176 = -28

Q(x) = [0, 40, 130, 227, 255]
```

**优点**:
- 量化范围利用率高
- 适合非对称分布（如 ReLU 后的激活值）

**缺点**:
- 需要额外存储零点
- 计算复杂度稍高

**适用场景**: 激活值量化（通常非对称分布）

---

### 1.1.3 量化粒度

#### 逐张量量化 (Per-Tensor Quantization)

**定义**: 整个张量共享一个 (s, z) 参数对

```python
# 示例：量化整个权重矩阵
W = [[1.2, -0.5, 2.1],
     [0.8,  1.5, -1.0],
     [-0.3, 0.9, 1.7]]

s = (2.1 - (-1.0)) / 255 = 0.0122
z = 82

Q(W) = [[180, 41, 254],
        [147, 205, 0],
        [58, 156, 221]]
```

**优点**: 参数量小（每个张量仅 2 个参数）
**缺点**: 量化精度较低

---

#### 逐通道量化 (Per-Channel Quantization)

**定义**: 每个输出通道独立计算 (s, z)

```python
# 卷积层权重: [out_channels, in_channels, H, W]
# 每个 out_channel 独立量化

for i in range(out_channels):
    channel_weights = W[i, :, :, :]
    s[i] = (channel_weights.max() - channel_weights.min()) / 255
    z[i] = -channel_weights.min() / s[i]
    Q(W)[i] = quantize(channel_weights, s[i], z[i])
```

**优点**: 量化精度显著提升（特别是卷积层）
**缺点**: 参数量增加（out_channels × 2）

**实验结果**:
```
ResNet-50 量化精度对比:
- Per-Tensor INT8:  准确率 69.2% (↓ 7.1%)
- Per-Channel INT8: 准确率 75.8% (↓ 0.5%)
```

---

#### 逐组量化 (Per-Group Quantization)

**定义**: 将通道分组，每组共享量化参数

```python
# GPTQ/AWQ 采用的方法
# 将 4096 维度分为 128 组，每组 32 个元素

group_size = 32
num_groups = 4096 // 32  # 128 组

for g in range(num_groups):
    group_weights = W[:, g*group_size : (g+1)*group_size]
    s[g], z[g] = compute_scale_zp(group_weights)
    Q(W)[:, g*group_size : (g+1)*group_size] = quantize(group_weights, s[g], z[g])
```

**权衡**: 精度和参数量的平衡

### 1.1.4 量化位宽

| 位宽 | 范围 (有符号) | 范围 (无符号) | 压缩比 | 典型用途 |
|------|--------------|--------------|--------|---------|
| **FP32** | ±3.4×10³⁸ | - | 1x | 训练基线 |
| **FP16** | ±65504 | - | 2x | 训练/推理 |
| **INT8** | [-128, 127] | [0, 255] | 4x | 推理（生产） |
| **INT4** | [-8, 7] | [0, 15] | 8x | 极致压缩 |
| **INT2** | [-2, 1] | [0, 3] | 16x | 研究阶段 |

**位宽选择经验**:
```
模型大小 > 7B  → INT4 (可接受 3-5% 精度损失)
模型大小 1-7B  → INT8 (推荐, <2% 精度损失)
模型大小 < 1B  → FP16 (已足够小)
```

## 1.2 量化方法分类

### 1.2.1 训练后量化 (PTQ)

#### 动态量化 (Dynamic Quantization)

**原理**: 权重离线量化，激活值运行时量化

```python
# 伪代码流程
# 初始化阶段
quantized_weight = quantize(weight)  # 离线计算

# 推理阶段
def forward(x):
    # 1. 动态量化激活值
    x_scale, x_zp = compute_scale_zp(x)  # ← 运行时计算
    x_quant = quantize(x, x_scale, x_zp)

    # 2. 整数矩阵乘法
    y_quant = matmul_int8(x_quant, quantized_weight)

    # 3. 反量化输出
    y = dequantize(y_quant, x_scale * weight_scale)
    return y
```

**优点**:
- 无需校准数据
- 实现简单
- 适合变长输入（NLP 任务）

**缺点**:
- 激活值量化开销（首 token 延迟增加）
- 精度略低于静态量化

**PyTorch 实现**:
```python
import torch
from torch.quantization import quantize_dynamic

model = MyModel()

# 动态量化线性层和 LSTM
quantized_model = quantize_dynamic(
    model,
    qconfig_spec={torch.nn.Linear, torch.nn.LSTM},
    dtype=torch.qint8
)

# 推理
output = quantized_model(input_data)
```

#### 静态量化 (Static Quantization)

**原理**: 使用校准数据集预先统计激活值范围

```python
# 步骤 1: 插入观察器 (Observer)
model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
prepared_model = torch.quantization.prepare(model, inplace=False)

# 步骤 2: 校准 (Calibration)
with torch.no_grad():
    for batch in calibration_dataloader:  # 100-1000 个样本
        prepared_model(batch)
        # Observer 自动统计激活值的 min/max

# 步骤 3: 转换为量化模型
quantized_model = torch.quantization.convert(prepared_model, inplace=False)

# 推理 (全整数计算)
output = quantized_model(input_data)
```

**Observer 机制**:
```python
class MinMaxObserver:
    def __init__(self):
        self.min_val = float('inf')
        self.max_val = float('-inf')

    def __call__(self, x):
        # 统计激活值范围
        self.min_val = min(self.min_val, x.min().item())
        self.max_val = max(self.max_val, x.max().item())

    def calculate_qparams(self):
        # 计算量化参数
        scale = (self.max_val - self.min_val) / 255
        zero_point = -round(self.min_val / scale)
        return scale, zero_point
```

**优点**:
- 精度最高（充分利用校准数据）
- 推理全整数化（极致性能）

**缺点**:
- 需要校准数据
- 对分布偏移敏感

#### 权重仅量化 (Weight-Only Quantization)

**原理**: 仅量化权重，激活值保持 FP16

```python
# 适用场景: 内存受限但计算充足 (如大模型推理)

class WeightOnlyLinear(nn.Module):
    def __init__(self, in_features, out_features):
        super().__init__()
        # 存储量化权重 (INT4/INT8)
        self.weight_q = None  # [out, in] INT8
        self.scale = None     # [out] FP16
        self.zero_point = None

    def forward(self, x):
        # x: [batch, seq, in_features] FP16

        # 1. 反量化权重 (运行时)
        weight_fp16 = (self.weight_q.float() + self.zero_point) * self.scale

        # 2. FP16 矩阵乘法
        output = F.linear(x, weight_fp16)

        return output
```

**性能分析**:
```
模型: LLaMA-7B

方案              内存占用    推理速度    精度
--------------------------------------------------
FP16              13 GB      100 ms      100%
Weight-Only INT8  7 GB       95 ms       99.5%
Weight-Only INT4  3.5 GB     90 ms       98%
Full INT8         7 GB       60 ms       99%
```

**适用场景**: 内存墙问题（显存受限，计算充足）

### 1.2.2 量化感知训练 (QAT)

**原理**: 在训练时模拟量化，让模型适应量化噪声

#### 前向传播中的伪量化

```python
class FakeQuantize(nn.Module):
    """伪量化模块：模拟量化但保持梯度流动"""

    def __init__(self, scale, zero_point):
        super().__init__()
        self.scale = nn.Parameter(torch.tensor(scale))
        self.zero_point = nn.Parameter(torch.tensor(zero_point))

    def forward(self, x):
        # 1. 量化
        x_q = torch.clamp(
            torch.round(x / self.scale) + self.zero_point,
            0, 255
        )

        # 2. 反量化 (保持 FP32 用于梯度计算)
        x_dq = (x_q - self.zero_point) * self.scale

        # 3. Straight-Through Estimator (STE)
        # 前向: 使用量化值
        # 反向: 直通梯度
        return x_dq + (x - x).detach()  # 等价于 x_dq
```

**STE (Straight-Through Estimator)**:
```
梯度计算:
    ∂L/∂x = ∂L/∂x_dq * ∂x_dq/∂x_q * ∂x_q/∂x

    其中 ∂x_q/∂x 在 round() 处不可导
    STE 近似: ∂x_q/∂x ≈ 1

    因此: ∂L/∂x ≈ ∂L/∂x_dq
```

---

#### QAT 完整流程

```python
import torch
import torch.nn as nn
from torch.quantization import prepare_qat, convert

# 1. 定义模型
class MyModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(3, 64, 3)
        self.bn1 = nn.BatchNorm2d(64)
        self.relu = nn.ReLU()
        self.fc = nn.Linear(64, 10)

    def forward(self, x):
        x = self.conv1(x)
        x = self.bn1(x)
        x = self.relu(x)
        x = x.mean([2, 3])  # Global Average Pooling
        x = self.fc(x)
        return x

model = MyModel()

# 2. 融合层 (Conv + BN + ReLU)
model.fuse_model()  # 提升量化精度

# 3. 配置 QAT
model.qconfig = torch.quantization.get_default_qat_qconfig('fbgemm')
prepared_model = prepare_qat(model.train())

# 4. 训练 (带伪量化)
optimizer = torch.optim.SGD(prepared_model.parameters(), lr=0.01)

for epoch in range(10):  # QAT 通常需要 5-10 epoch
    for batch in train_loader:
        optimizer.zero_grad()

        # 前向 (自动插入伪量化)
        output = prepared_model(batch['image'])
        loss = criterion(output, batch['label'])

        # 反向 (STE 梯度)
        loss.backward()
        optimizer.step()

# 5. 转换为真实量化模型
prepared_model.eval()
quantized_model = convert(prepared_model)

# 6. 保存
torch.jit.save(torch.jit.script(quantized_model), "model_qat.pt")
```

## 1.3 量化误差分析

### 1.3.1 量化误差的来源

#### 1. 截断误差 (Clipping Error)

**定义**: 超出量化范围的值被截断

```python
x = [-150, -50, 0, 100, 200]  # 原始值
# INT8 范围: [-128, 127]

x_clipped = [-128, -50, 0, 100, 127]  # 截断
error = [22, 0, 0, 0, 73]  # 截断误差

# 相对误差
relative_error = sum(error) / sum(abs(x)) = 95 / 500 = 19%
```

**解决方法**:
```python
# 方法 1: 扩大量化范围 (使用 99.9 分位数)
x_max = np.percentile(x, 99.9)
x_min = np.percentile(x, 0.1)

# 方法 2: 异常值检测
outliers = x[abs(x - x.mean()) > 3 * x.std()]
x_filtered = x[~outliers]
```

---

#### 2. 舍入误差 (Rounding Error)

**定义**: round() 操作引入的误差

```python
x = [1.3, 1.5, 1.7]
s = 0.1

# 量化
x_q = round(x / s) = [13, 15, 17]

# 反量化
x_dq = x_q * s = [1.3, 1.5, 1.7]

# 舍入误差
error = x - x_dq = [0.0, 0.0, 0.0]  # 恰好能表示

# 但是
y = [1.32, 1.55, 1.78]
y_q = round(y / s) = [13, 16, 18]
y_dq = [1.3, 1.6, 1.8]
error = [0.02, -0.05, -0.02]  # 不可避免的误差
```

**误差界**:
```
量化误差上界:
    |x - Q(x)| ≤ s / 2

其中 s 是缩放因子
```

---

#### 3. 累积误差 (Accumulation Error)

**定义**: 多层量化导致误差累积

```python
# 3 层网络示例
x = input  # FP32

# 第 1 层
w1_q = quantize(w1)  # 量化误差 ε₁
y1 = matmul(x, w1_q)  # y1 = xW₁ + ε₁x

# 第 2 层
w2_q = quantize(w2)
y2 = matmul(y1, w2_q)  # y2 = (xW₁ + ε₁x)W₂ + ε₂y1
                        #    = xW₁W₂ + ε₁xW₂ + ε₂xW₁ + ε₁ε₂x

# 误差项累积增长！
```

**缓解策略**:
```python
# 1. 残差连接 (跳过量化)
class QuantizedResBlock(nn.Module):
    def forward(self, x):
        identity = x  # FP16/FP32

        out = self.quant_conv1(x)  # 量化分支
        out = self.quant_conv2(out)

        out = out + identity  # 加上原始输入（缓解累积）
        return out

# 2. 混合精度 (关键层保持高精度)
model.layer1.quantize = False  # 第一层 FP16
model.layer50.quantize = False  # 最后一层 FP16
```

### 1.3.2 量化误差的度量

#### MSE (均方误差)

```python
def quantization_mse(weight_fp32, weight_int8, scale, zero_point):
    """计算量化前后的 MSE"""
    # 反量化
    weight_dequant = (weight_int8.float() - zero_point) * scale

    # MSE
    mse = torch.mean((weight_fp32 - weight_dequant) ** 2)

    return mse.item()

# 示例
mse = quantization_mse(W_original, W_quantized, s, z)
print(f"量化 MSE: {mse:.6f}")
```

#### SQNR (信噪比)

```python
def quantization_sqnr(signal, quantized_signal):
    """
    SQNR = 10 * log10(Power_signal / Power_noise)
    """
    noise = signal - quantized_signal

    signal_power = torch.mean(signal ** 2)
    noise_power = torch.mean(noise ** 2)

    sqnr = 10 * torch.log10(signal_power / noise_power)

    return sqnr.item()

# 典型值
# SQNR > 30 dB: 高质量量化
# SQNR 20-30 dB: 可接受
# SQNR < 20 dB: 质量差，需优化
```

#### 余弦相似度

```python
def cosine_similarity_quantization(x, x_q):
    """衡量量化前后向量方向的保持程度"""
    x_flat = x.flatten()
    x_q_flat = x_q.flatten()

    cos_sim = F.cosine_similarity(x_flat, x_q_flat, dim=0)

    return cos_sim.item()

# 高质量量化: cos_sim > 0.99
```

## 1.4 高级量化技术

### 1.4.1 混合精度量化 (Mixed-Precision Quantization)

**原理**: 不同层使用不同位宽

#### 敏感度分析

```python
def layer_sensitivity_analysis(model, val_loader):
    """
    分析每层对量化的敏感度
    """
    sensitivity = {}

    # 基线精度
    baseline_acc = evaluate(model, val_loader)

    # 逐层量化并测试
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            # 临时量化该层
            original_weight = module.weight.data.clone()
            module.weight.data = quantize_dequantize(original_weight, bits=8)

            # 评估精度
            quantized_acc = evaluate(model, val_loader)
            sensitivity[name] = baseline_acc - quantized_acc

            # 恢复权重
            module.weight.data = original_weight

    # 按敏感度排序
    sorted_layers = sorted(sensitivity.items(), key=lambda x: x[1], reverse=True)

    return sorted_layers

# 使用结果
sensitivity = layer_sensitivity_analysis(model, val_loader)

# 示例输出
# layer1.conv:  -5.2%  ← 高敏感（保持 FP16）
# layer2.conv:  -0.3%  ← 低敏感（可用 INT4）
# layer50.fc:   -4.8%  ← 高敏感（保持 FP16）
```

#### 自动混合精度搜索

```python
class AutoMixedPrecision:
    """基于强化学习的位宽搜索"""

    def __init__(self, model, target_size_mb=1000):
        self.model = model
        self.target_size = target_size_mb
        self.bit_choices = [2, 4, 8, 16]  # 可选位宽

    def search(self, val_loader):
        """搜索最优位宽配置"""
        best_config = None
        best_accuracy = 0

        for config in self.generate_configs():
            # 应用配置
            quantized_model = self.apply_config(config)

            # 检查大小约束
            model_size = self.compute_size(quantized_model)
            if model_size > self.target_size:
                continue

            # 评估精度
            accuracy = evaluate(quantized_model, val_loader)

            if accuracy > best_accuracy:
                best_accuracy = accuracy
                best_config = config

        return best_config, best_accuracy

    def generate_configs(self):
        """生成候选配置（可用遗传算法、强化学习等）"""
        # 简化版: 随机搜索
        for _ in range(1000):
            config = {}
            for name, module in self.model.named_modules():
                if isinstance(module, (nn.Linear, nn.Conv2d)):
                    config[name] = random.choice(self.bit_choices)
            yield config
```

### 1.4.2 GPTQ (Accurate Post-Training Quantization)

**核心思想**: 最小化量化前后输出的 MSE

#### 数学推导

```
目标: 找到量化权重 Ŵ，使得输出误差最小

min ||XW - XŴ||²
 Ŵ

其中:
  X: 激活值矩阵 [n_samples, in_features]
  W: 原始权重 [in_features, out_features]
  Ŵ: 量化权重

等价于:
min ||W - Ŵ||²_H
 Ŵ

其中 H = X^T X 是 Hessian 矩阵
```

---

#### GPTQ 算法

```python
import torch
import torch.nn as nn

class GPTQuantizer:
    """GPTQ 量化算法实现"""

    def __init__(self, weight, bits=4, group_size=128):
        """
        参数:
            weight: [out_features, in_features]
            bits: 量化位宽
            group_size: 分组大小
        """
        self.weight = weight
        self.bits = bits
        self.group_size = group_size
        self.out_features, self.in_features = weight.shape

    def quantize(self, X):
        """
        X: 校准数据激活值 [n_samples, in_features]
        """
        # 1. 计算 Hessian
        H = X.T @ X / X.shape[0]  # [in_features, in_features]
        H_inv = torch.linalg.inv(H + 1e-6 * torch.eye(self.in_features).to(H.device))

        # 2. 初始化量化权重
        W_q = torch.zeros_like(self.weight)

        # 3. 逐列量化 (从左到右)
        for i in range(0, self.in_features, self.group_size):
            # 当前分组
            group_end = min(i + self.group_size, self.in_features)
            W_group = self.weight[:, i:group_end]  # [out, group_size]

            # 量化参数
            w_max = W_group.abs().max()
            scale = w_max / (2 ** (self.bits - 1) - 1)

            # 量化
            W_q_group = torch.clamp(
                torch.round(W_group / scale),
                -(2 ** (self.bits - 1)),
                2 ** (self.bits - 1) - 1
            )
            W_dq_group = W_q_group * scale

            # 4. 误差补偿 (关键！)
            error = W_group - W_dq_group  # [out, group_size]

            # 将误差分配到后续列
            for j in range(group_end, self.in_features):
                # 使用 Hessian 逆矩阵计算最优补偿
                compensation = error @ H_inv[i:group_end, j]
                self.weight[:, j] += compensation

            W_q[:, i:group_end] = W_q_group

        return W_q, scale

# 使用示例
model = AutoModelForCausalLM.from_pretrained("Qwen/Qwen-7B")

# 收集校准数据
calibration_data = []
for batch in calibration_loader:
    with torch.no_grad():
        _ = model(**batch)  # 前向传播，收集激活值

# 逐层量化
for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        # 获取该层的激活值
        X = activation_cache[name]  # [n_samples, in_features]

        # GPTQ 量化

        W_q, scale = quantizer.quantize(X)

        # 替换权重
        module.weight.data = W_q
        module.scale = scale
```

**GPTQ 特点**:
- **精度高**: 误差补偿机制显著减少累积误差
- **速度快**: 单次前向传播即可完成量化（无需训练）
- **适用性强**: 特别适合 LLM 的 4-bit 量化

### 1.4.3 AWQ (Activation-aware Weight Quantization)

**核心思想**: 保护重要权重不被量化

#### 权重重要性分析

```python
def compute_weight_importance(model, calibration_data):
    """
    基于激活值计算权重重要性
    """
    importance = {}

    # 注册钩子收集激活值
    activations = {}
    def hook_fn(name):
        def hook(module, input, output):
            activations[name] = input[0].detach()
        return hook

    hooks = []
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            hooks.append(module.register_forward_hook(hook_fn(name)))

    # 前向传播
    with torch.no_grad():
        for batch in calibration_data:
            _ = model(**batch)

    # 移除钩子
    for hook in hooks:
        hook.remove()

    # 计算重要性: importance = ||X||_2 (L2 范数)
    for name, X in activations.items():
        # X: [batch, seq_len, hidden]
        importance[name] = X.abs().mean(dim=[0, 1])  # [hidden]

    return importance
```

#### AWQ 量化算法

```python
class AWQQuantizer:
    """AWQ 量化: 重要通道保持高精度"""

    def __init__(self, weight, importance, bits=4, alpha=0.5):
        """
        参数:
            weight: [out_features, in_features]
            importance: [in_features] 每个输入通道的重要性
            alpha: 缩放系数
        """
        self.weight = weight
        self.importance = importance
        self.bits = bits
        self.alpha = alpha

    def quantize(self):
        # 1. 计算缩放因子 (基于重要性)
        s = self.importance ** self.alpha  # [in_features]

        # 2. 缩放权重 (降低重要通道的量化步长)
        W_scaled = self.weight / s.unsqueeze(0)  # [out, in] / [1, in]

        # 3. 逐通道量化
        W_q = []
        scales = []

        for i in range(self.weight.shape[0]):  # 遍历输出通道
            w = W_scaled[i]  # [in_features]

            # 量化参数
            w_max = w.abs().max()
            scale = w_max / (2 ** (self.bits - 1) - 1)

            # 量化
            w_q = torch.clamp(
                torch.round(w / scale),
                -(2 ** (self.bits - 1)),
                2 ** (self.bits - 1) - 1
            )

            W_q.append(w_q)
            scales.append(scale)

        W_q = torch.stack(W_q)  # [out, in]
        scales = torch.tensor(scales)  # [out]

        # 4. 推理时的缩放调整
        # y = (W_q * scales) @ (x / s) = W_q @ x' * (scales / s)
        return W_q, scales, s

# 使用示例
importance = compute_weight_importance(model, calibration_data)

for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        quantizer = AWQQuantizer(
            module.weight.data,
            importance[name],
            bits=4,
            alpha=0.5
        )
        W_q, scales, s = quantizer.quantize()

        # 保存量化参数
        module.weight_q = W_q
        module.scales = scales
        module.importance_scale = s
```

```python
import torch
import torch.nn as nn
from transformers import AutoModelForCausalLM, AutoTokenizer

class QuantizationPipeline:
    """端到端量化流程"""

    def __init__(self, model_name, bits=8):
        self.model_name = model_name
        self.bits = bits
        self.model = None
        self.tokenizer = None

    def load_model(self):
        """加载原始模型"""
        print("1. 加载模型...")
        self.model = AutoModelForCausalLM.from_pretrained(
            self.model_name,
            torch_dtype=torch.float16,
            device_map="auto"
        )
        self.tokenizer = AutoTokenizer.from_pretrained(self.model_name)

        # 基线评估
        baseline_ppl = self.evaluate()
        print(f"   基线困惑度: {baseline_ppl:.2f}")
        return baseline_ppl

    def calibrate(self, calibration_texts):
        """校准阶段"""
        print("2. 校准量化参数...")

        # 插入观察器
        self.model.qconfig = torch.quantization.get_default_qconfig('fbgemm')
        self.prepared_model = torch.quantization.prepare(self.model, inplace=False)

        # 前向传播收集统计信息
        self.prepared_model.eval()
        with torch.no_grad():
            for text in calibration_texts:
                inputs = self.tokenizer(text, return_tensors="pt").to(self.model.device)
                _ = self.prepared_model(**inputs)

        print("   校准完成")

    def quantize(self):
        """执行量化"""
        print("3. 转换为量化模型...")
        self.quantized_model = torch.quantization.convert(
            self.prepared_model,
            inplace=False
        )

        # 量化后评估
        quantized_ppl = self.evaluate(use_quantized=True)
        print(f"   量化后困惑度: {quantized_ppl:.2f}")

        return quantized_ppl

    def evaluate(self, use_quantized=False):
        """评估困惑度"""
        model = self.quantized_model if use_quantized else self.model

        # 使用 WikiText 评估
        from datasets import load_dataset
        testdata = load_dataset('wikitext', 'wikitext-2-raw-v1', split='test')

        total_loss = 0
        total_tokens = 0

        model.eval()
        with torch.no_grad():
            for text in testdata['text'][:100]:  # 采样 100 条
                if len(text.strip()) == 0:
                    continue

                inputs = self.tokenizer(text, return_tensors="pt").to(model.device)
                outputs = model(**inputs, labels=inputs["input_ids"])

                total_loss += outputs.loss.item() * inputs["input_ids"].numel()
                total_tokens += inputs["input_ids"].numel()

        ppl = torch.exp(torch.tensor(total_loss / total_tokens))
        return ppl.item()

    def save(self, output_path):
        """保存量化模型"""
        print(f"4. 保存模型到 {output_path}...")

        # 方法 1: PyTorch 格式
        torch.save(self.quantized_model.state_dict(), f"{output_path}/model.pth")

        # 方法 2: TorchScript 格式 (推理优化)
        scripted_model = torch.jit.script(self.quantized_model)
        scripted_model.save(f"{output_path}/model_scripted.pt")

        # 保存配置
        import json
        config = {
            "model_name": self.model_name,
            "bits": self.bits,
            "quantization_method": "static_int8"
        }
        with open(f"{output_path}/config.json", "w") as f:
            json.dump(config, f)
```

```python
def fix_quantization_overflow(model, calibration_data):
    """修复量化溢出问题"""

    # 1. 检测异常值
    def detect_outliers(tensor, threshold=3.0):
        mean = tensor.mean()
        std = tensor.std()
        outliers = tensor[torch.abs(tensor - mean) > threshold * std]
        return outliers

    # 2. 收集激活值统计
    activations = {}

    def hook_fn(name):
        def hook(module, input, output):
            activations[name] = output.detach()
        return hook

    hooks = []
    for name, module in model.named_modules():
        if isinstance(module, nn.Linear):
            hooks.append(module.register_forward_hook(hook_fn(name)))

    # 前向传播
    with torch.no_grad():
        for batch in calibration_data:
            _ = model(**batch)

    for hook in hooks:
        hook.remove()

    # 3. 分析异常值
    print("激活值统计:")
    for name, act in activations.items():
        outliers = detect_outliers(act)

        if len(outliers) > 0:
            print(f"  ⚠️  {name}:")
            print(f"      均值: {act.mean():.4f}")
            print(f"      标准差: {act.std():.4f}")
            print(f"      最大值: {act.max():.4f}")
            print(f"      异常值数量: {len(outliers)} / {act.numel()}")

            # 解决方案: 使用百分位数截断
            percentile_99 = torch.quantile(act.abs(), 0.99)
            print(f"      建议使用 99 分位数: {percentile_99:.4f}")

    return activations
```

```python
def optimize_batch_inference(model, inputs, batch_size=8):
    """批量推理优化"""

    # 原始方式: 逐条推理
    outputs_naive = []
    for input in inputs:
        output = model(input.unsqueeze(0))  # [1, ...]
        outputs_naive.append(output)

    outputs_batched = []
    for i in range(0, len(inputs), batch_size):
        batch = torch.stack(inputs[i:i+batch_size])  # [batch_size, ...]
        output = model(batch)
        outputs_batched.append(output)

    outputs_batched = torch.cat(outputs_batched)

    return outputs_batched
```
