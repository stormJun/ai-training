## 概述

### 为什么需要小型模型

大型语言模型（LLM）虽然能力强大，但在实际部署中面临诸多挑战：

| 挑战 | 问题描述 | 解决方案 |
|------|---------|---------|
| **推理成本高** | GPT-3.5/GPT-4 每次调用都需要付费 | 本地部署小型模型 |
| **延迟高** | 云端 API 调用 RTT 500ms-2s | 边缘设备实时推理 |
| **隐私问题** | 敏感数据不能上传云端 | 私有化部署 |
| **资源受限** | 移动设备/IoT 无法运行大模型 | 压缩到 <1GB |
| **离线需求** | 无网络环境下无法使用 | 离线模型 |

**小型模型优化的目标**：
- 将 7B-13B 参数模型压缩到 1B-3B
- 推理速度提升 3-10 倍
- 内存占用减少 50%-75%
- 保持 90%+ 的原始性能

---

### 优化目标和权衡

```
              模型性能
                 ▲
                 │
                 │  ● 原始模型 (7B 参数)
                 │
                 │      ● 蒸馏模型 (保留 92% 性能)
                 │
                 │         ● 量化模型 (保留 88% 性能)
                 │
                 │            ● 剪枝模型 (保留 85% 性能)
                 │
                 └─────────────────────────────────► 模型大小/速度
```

**优化维度**:
1. **模型大小** (Model Size): 磁盘占用、下载速度
2. **推理速度** (Inference Speed): 首 token 延迟、吞吐量
3. **内存占用** (Memory Usage): 峰值显存/内存
4. **精度损失** (Accuracy Drop): 任务性能下降幅度

## 一、权重量化 (Quantization)

### 理论基础

**量化定义**: 将高精度浮点数 (FP32/FP16) 映射到低精度整数 (INT8/INT4)

**数学原理**:
```
量化公式:
    q = round((x - zero_point) / scale)

反量化公式:
    x' = q * scale + zero_point

其中:
    - x: 原始浮点权重
    - q: 量化后的整数
    - scale: 缩放因子
    - zero_point: 零点偏移
```

**示例**:
```python
# FP32 权重范围: [-1.5, 2.3]
weights = [-1.5, -0.8, 0.0, 1.2, 2.3]

# 量化到 INT8 [-128, 127]
scale = (2.3 - (-1.5)) / 255 = 0.0149
zero_point = -128 - round(-1.5 / scale) = -28

# 量化结果
quantized = [-128, -82, -28, 52, 127]

# 内存占用: 32 bits → 8 bits (4x 压缩)
```

---

### 量化类型

#### 1. 训练后量化 (Post-Training Quantization, PTQ)

**特点**: 无需重新训练，直接量化预训练模型

**分类**:
- **动态量化**: 运行时量化激活值
- **静态量化**: 校准数据集统计激活值范围
- **仅权重量化**: 只量化权重，激活保持 FP16

**适用场景**: 快速部署，对精度要求不极致

---

#### 2. 量化感知训练 (Quantization-Aware Training, QAT)

**特点**: 训练时模拟量化，模型学习适应低精度

**优势**: 精度损失最小 (通常 <1%)

**劣势**: 需要训练数据和 GPU 资源

---

## 二、权重剪枝 (Pruning)

### 剪枝原理

**核心思想**: 移除对模型性能贡献小的权重连接

**彩票假设 (Lottery Ticket Hypothesis)**:
> 大型神经网络中存在"中奖子网络"，该子网络可以单独训练达到原网络性能

**剪枝依据**:
1. **权重大小**: |w| 小的权重贡献小
2. **梯度信息**: 梯度小的权重不重要
3. **激活值**: 输出为 0 的神经元可删除

---

### 剪枝策略

#### 1. 非结构化剪枝 (Unstructured Pruning)

**定义**: 删除单个权重元素

**优点**: 压缩比高 (可达 90%+ 稀疏度)
**缺点**: 需要稀疏矩阵运算库，硬件加速有限

```python
# 权重矩阵示例
原始:
[0.8  -0.3   0.1   0.9]
[0.2   0.0  -0.7   0.4]
[0.5   0.3   0.2  -0.1]

剪枝后 (阈值 0.3):
[0.8   0.0   0.0   0.9]
[0.0   0.0  -0.7   0.4]
[0.5   0.3   0.0   0.0]

稀疏度: 50%
```

---

#### 2. 结构化剪枝 (Structured Pruning)

**定义**: 删除整个神经元、通道或层

**优点**: 硬件友好，实际加速明显
**缺点**: 压缩比较低

**类型**:
- **通道剪枝**: 删除卷积层的整个通道
- **头剪枝**: 删除 Transformer 的注意力头
- **层剪枝**: 删除整层 (如删除 24 层中的 4 层)

---

### 实践代码

#### 非结构化剪枝 (L1 范数)

```python
import torch
import torch.nn.utils.prune as prune
from transformers import AutoModelForCausalLM

# 加载模型
model = AutoModelForCausalLM.from_pretrained("EleutherAI/gpt-neo-125M")

# 1. 全局非结构化剪枝
parameters_to_prune = []
for name, module in model.named_modules():
    if isinstance(module, torch.nn.Linear):
        parameters_to_prune.append((module, 'weight'))

# L1 范数剪枝 (删除 30% 最小权重)
prune.global_unstructured(
    parameters_to_prune,
    pruning_method=prune.L1Unstructured,
    amount=0.3  # 剪枝比例
)

# 2. 查看剪枝效果
for module, param_name in parameters_to_prune[:2]:
    print(f"稀疏度: {100. * float(torch.sum(module.weight == 0)) / module.weight.nelement():.2f}%")
    # 输出: 稀疏度: 30.00%

# 3. 永久移除剪枝参数化
for module, _ in parameters_to_prune:
    prune.remove(module, 'weight')

# 4. 保存剪枝模型
torch.save(model.state_dict(), "model_pruned.pth")
```

#### 结构化剪枝 (通道剪枝)

```python
def prune_transformer_heads(model, num_heads_to_prune=2):
    """
    剪枝 Transformer 注意力头
    """
    for layer in model.transformer.h:
        # 计算每个头的重要性分数
        attention_weights = layer.attn.c_attn.weight.data
        head_importance = []

        num_heads = layer.attn.num_heads
        head_dim = attention_weights.shape[0] // num_heads

        for i in range(num_heads):
            start_idx = i * head_dim
            end_idx = (i + 1) * head_dim
            head_weight = attention_weights[start_idx:end_idx]
            importance = torch.norm(head_weight, p=2).item()
            head_importance.append((i, importance))

        # 找到最不重要的头
        head_importance.sort(key=lambda x: x[1])
        heads_to_prune = [h[0] for h in head_importance[:num_heads_to_prune]]

        # 标记剪枝的头
        layer.attn.pruned_heads = set(heads_to_prune)

        print(f"剪枝头: {heads_to_prune}, 重要性: {[h[1] for h in head_importance[:num_heads_to_prune]]}")

# 执行剪枝
prune_transformer_heads(model, num_heads_to_prune=2)
```

def prune_transformer_layers(model, layers_to_drop=[2, 5, 8, 11]):
    """
    删除指定层
    """
    total_layers = len(model.transformer.h)

    # 创建新的层列表
    new_layers = torch.nn.ModuleList([
        layer for i, layer in enumerate(model.transformer.h)
        if i not in layers_to_drop
    ])

    # 替换
    model.transformer.h = new_layers

    print(f"原始层数: {total_layers}, 剪枝后: {len(new_layers)}")
    return model

# 删除 4 层 (从 12 层降到 8 层)
model = prune_transformer_layers(model, layers_to_drop=[2, 5, 8, 11])

#### 渐进式剪枝 (Iterative Magnitude Pruning)

```python
def iterative_pruning(model, train_loader, initial_sparsity=0.0, final_sparsity=0.9, steps=10):
    """
    逐步提高剪枝比例，并微调模型
    """
    for step in range(steps):
        # 计算当前剪枝比例
        current_sparsity = initial_sparsity + (final_sparsity - initial_sparsity) * (step / steps)

        # 剪枝
        parameters_to_prune = [
            (module, 'weight') for name, module in model.named_modules()
            if isinstance(module, torch.nn.Linear)
        ]
        prune.global_unstructured(
            parameters_to_prune,
            pruning_method=prune.L1Unstructured,
            amount=current_sparsity
        )

        # 微调 1 个 epoch
        train_one_epoch(model, train_loader)

        print(f"Step {step+1}/{steps}, 稀疏度: {current_sparsity:.1%}")

    return model
```

## 三、知识蒸馏 (Knowledge Distillation)

### 蒸馏原理

**核心思想**: 用大模型 (教师) 的"软知识"训练小模型 (学生)

**为什么有效**:
1. **软标签更丰富**: 教师输出的概率分布包含更多信息
   ```
   硬标签: [0, 0, 1, 0]  (仅告诉正确答案)
   软标签: [0.05, 0.15, 0.65, 0.15]  (告诉相似度关系)
   ```

2. **暗知识传递**: 教师的错误也有价值 (如 "猫" 和 "狗" 比 "汽车" 更相似)

3. **平滑优化**: 软标签使损失函数更平滑，易于优化

---

**温度参数 (Temperature)**:
```python
# 高温 (T=5) → 更平滑的概率分布
logits = [2.0, 1.0, 0.5]

T=1:  softmax([2.0, 1.0, 0.5]) = [0.66, 0.24, 0.10]  # 硬分布
T=5:  softmax([0.4, 0.2, 0.1]) = [0.43, 0.35, 0.22]  # 软分布 (更均匀)
```

---

### 蒸馏方法

#### 1. 经典蒸馏 (Response-Based)

**损失函数**:
```python
L_distill = α * L_hard + (1-α) * L_soft

其中:
  L_hard = CE(y_true, y_student)      # 交叉熵 (硬标签)
  L_soft = KL(y_teacher, y_student)   # KL 散度 (软标签)
  α = 0.1-0.3  (硬标签权重)
```

---

#### 2. 特征蒸馏 (Feature-Based)

**思想**: 不仅学习输出，还学习中间层表示

```python
L_feature = MSE(hidden_teacher, hidden_student)
L_total = L_distill + β * L_feature
```

---

#### 3. 关系蒸馏 (Relation-Based)

**思想**: 学习样本之间的关系

```python
# 教师模型的样本相似度矩阵
similarity_teacher = cosine_similarity(features_teacher)

# 学生模型的样本相似度矩阵
similarity_student = cosine_similarity(features_student)

L_relation = MSE(similarity_teacher, similarity_student)
```

### 实践代码

#### 基础蒸馏实现

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from transformers import AutoModelForCausalLM, AutoTokenizer

# 1. 加载教师和学生模型
teacher = AutoModelForCausalLM.from_pretrained("Qwen/Qwen-7B")
student = AutoModelForCausalLM.from_pretrained("Qwen/Qwen-1.8B")

teacher.eval()  # 教师模型不更新参数
student.train()

# 2. 蒸馏损失函数
def distillation_loss(student_logits, teacher_logits, labels, temperature=2.0, alpha=0.1):
    """
    参数:
        student_logits: 学生模型输出 logits
        teacher_logits: 教师模型输出 logits
        labels: 真实标签
        temperature: 温度参数
        alpha: 硬标签权重
    """
    # 软标签损失 (KL 散度)
    soft_targets = F.softmax(teacher_logits / temperature, dim=-1)
    soft_prob = F.log_softmax(student_logits / temperature, dim=-1)
    soft_loss = F.kl_div(soft_prob, soft_targets, reduction='batchmean') * (temperature ** 2)

    # 硬标签损失 (交叉熵)
    hard_loss = F.cross_entropy(student_logits, labels)

    # 组合损失
    return alpha * hard_loss + (1 - alpha) * soft_loss

# 3. 训练循环
optimizer = torch.optim.AdamW(student.parameters(), lr=2e-5)

for epoch in range(3):
    for batch in train_dataloader:
        input_ids = batch["input_ids"].to("cuda")
        labels = batch["labels"].to("cuda")

        # 教师模型推理 (不计算梯度)
        with torch.no_grad():
            teacher_outputs = teacher(input_ids)
            teacher_logits = teacher_outputs.logits

        # 学生模型推理
        student_outputs = student(input_ids)
        student_logits = student_outputs.logits

        # 计算损失
        loss = distillation_loss(
            student_logits.view(-1, student_logits.size(-1)),
            teacher_logits.view(-1, teacher_logits.size(-1)),
            labels.view(-1),
            temperature=2.0,
            alpha=0.1
        )

        # 反向传播
        loss.backward()
        optimizer.step()
        optimizer.zero_grad()

        print(f"Epoch {epoch}, Loss: {loss.item():.4f}")

# 4. 保存学生模型
student.save_pretrained("qwen-1.8b-distilled")
```

#### 特征蒸馏 (中间层对齐)

```python
class FeatureDistillation(nn.Module):
    def __init__(self, teacher_dim=4096, student_dim=2048):
        super().__init__()
        # 投影层 (将学生特征映射到教师维度)
        self.projector = nn.Linear(student_dim, teacher_dim)

    def forward(self, student_hidden, teacher_hidden):
        """
        student_hidden: [batch, seq_len, student_dim]
        teacher_hidden: [batch, seq_len, teacher_dim]
        """
        # 投影学生特征
        student_projected = self.projector(student_hidden)

        # MSE 损失
        loss = F.mse_loss(student_projected, teacher_hidden)
        return loss

# 使用示例
feature_distiller = FeatureDistillation(teacher_dim=4096, student_dim=2048).to("cuda")

# 在训练循环中
teacher_hidden = teacher_outputs.hidden_states[-1]  # 最后一层隐藏状态
student_hidden = student_outputs.hidden_states[-1]

feature_loss = feature_distiller(student_hidden, teacher_hidden)
total_loss = distill_loss + 0.5 * feature_loss  # 特征损失权重 0.5
```

#### TinyBERT 风格的多层蒸馏

```python
def multi_layer_distillation(teacher_model, student_model, input_ids, attention_mask):
    """
    蒸馏所有层 + 注意力矩阵
    """
    # 获取所有隐藏层
    teacher_outputs = teacher_model(
        input_ids,
        attention_mask=attention_mask,
        output_hidden_states=True,
        output_attentions=True
    )
    student_outputs = student_model(
        input_ids,
        attention_mask=attention_mask,
        output_hidden_states=True,
        output_attentions=True
    )

    total_loss = 0

    # 1. 嵌入层蒸馏
    emb_loss = F.mse_loss(
        student_outputs.hidden_states[0],
        teacher_outputs.hidden_states[0]
    )
    total_loss += emb_loss

    # 2. 中间层蒸馏 (每隔几层对齐一次)
    num_teacher_layers = len(teacher_outputs.hidden_states) - 1  # 12 层
    num_student_layers = len(student_outputs.hidden_states) - 1  # 6 层
    layer_mapping = [0, 2, 4, 6, 8, 10, 12]  # 学生层 i 对齐教师层 layer_mapping[i]

    for student_layer_idx in range(num_student_layers):
        teacher_layer_idx = layer_mapping[student_layer_idx]

        hidden_loss = F.mse_loss(
            student_outputs.hidden_states[student_layer_idx + 1],
            teacher_outputs.hidden_states[teacher_layer_idx + 1]
        )
        total_loss += hidden_loss

    # 3. 注意力蒸馏
    for student_attn, teacher_attn in zip(student_outputs.attentions, teacher_outputs.attentions):
        attn_loss = F.mse_loss(student_attn, teacher_attn)
        total_loss += attn_loss * 0.1  # 较低权重

    # 4. 预测层蒸馏
    logit_loss = distillation_loss(
        student_outputs.logits,
        teacher_outputs.logits,
        labels=None,
        temperature=2.0
    )
    total_loss += logit_loss

    return total_loss
```

@torch.no_grad()
def generate_pseudo_labels(teacher, unlabeled_texts, tokenizer):

#### 3. 任务特定蒸馏

```python
# 为特定下游任务蒸馏
def task_specific_distillation(teacher, student, task="classification"):
    """
    针对特定任务优化蒸馏策略
    """
    if task == "classification":
        # 分类任务: 重点蒸馏 logits
        return lambda s, t, l: distillation_loss(s, t, l, alpha=0.1)

    elif task == "generation":
        # 生成任务: 重点蒸馏序列级概率
        def seq_distill_loss(student_logits, teacher_logits, labels):
            # 计算序列级概率
            student_log_probs = F.log_softmax(student_logits, dim=-1)
            teacher_probs = F.softmax(teacher_logits / 2.0, dim=-1)

            # 序列蒸馏
            return F.kl_div(student_log_probs, teacher_probs, reduction='batchmean')

        return seq_distill_loss

    elif task == "embedding":
        # 嵌入任务: 重点蒸馏表示
        return lambda s_h, t_h: F.mse_loss(s_h, t_h)
```
