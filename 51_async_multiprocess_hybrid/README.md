# 协程与多进程混合

本主题提供异步与多进程混合调度的示例工程。

## 内容

- `p21_async_multiprocess_hybrid/`
  - 示例工程目录
- `p21_async_multiprocess_hybrid/main.py`
  - 主入口
- `p21_async_multiprocess_hybrid/run_demo.py`
  - 运行演示脚本
- `p21_async_multiprocess_hybrid/strategies.py`
  - 调度策略示例

## 开始方式

- 从 `p21_async_multiprocess_hybrid/run_demo.py` 开始
- 环境准备可参考 `../47_asyncio_basics/README.md`
