# 工作流基础

这一组材料的作用，不是让你立刻去写复杂工作流，而是先建立“工作流编排为什么重要”的整体认识。

你可以把它看成 `02_workflows` 阶段的总前置阅读，它主要回答：

- 为什么简单链式调用不够
- 为什么真实 Agent 系统需要路由、容错、状态和编排
- 从课程讲稿、讲师笔记到工程总结，这条理解路径应该怎么走

---

## 建议阅读顺序

1. `01_基础对话链意图识别_设计.pdf`
   先看最早的设计材料，理解基础链、意图识别和任务拆解的出发点。

2. `02_工作流编排_讲师文稿.md`
   这是从讲师口述稿整理出来的阅读版，更适合先顺一遍主线。

3. `03_工作流编排_讲师笔记.md`
   这份比文稿更像结构化提纲，适合拿来补概念、对照选型和实现方式。

4. `14_深度思考总结.md`
   最后再看这份扩展总结，它已经从课堂内容延伸到了更完整的工程化视角。

---

## 文件之间是什么关系

- `02_工作流编排_讲师文稿.txt`
  原始转写稿，保留讲课口语风格。

- `02_工作流编排_讲师文稿.md`
  基于转写稿整理后的讲义版，去掉了大量口语化表达，更适合直接阅读。

- `03_工作流编排_讲师笔记.txt`
  原始课堂笔记。

- `03_工作流编排_讲师笔记.md`
  对课堂笔记做了重组，更强调概念、选型和工程实现脉络。

也就是说，这一组里：

- `.txt` 更像原始素材
- `.md` 更像学习材料

---

## 这一组真正要学什么

这一组不是在讲某一个 API，而是在帮你建立下面这些认识：

- Agent 不只是“调用一个模型”
- 工作流要考虑状态、路由、容错、降级和记忆
- 复杂系统里，代码阅读能力本身就是工程能力的一部分

如果后面你要继续看：

- 人机协同
- 记忆
- RAG 工作流
- 快照恢复

那么这一组其实就是它们的理论入口。

---

## 阅读建议

最推荐的方式是：

1. 先看 `.pdf` / `.md` 建立整体印象
2. 再去看后面的可运行示例
3. 最后回到 `14_深度思考总结.md` 做系统复盘

不要一开始就被长代码和大段工程细节淹没。

---

## 小结

这一组的价值在于，它帮你把“后面那些分散的示例”先串成一条线：

- 从基础链路
- 到工作流编排
- 再到更完整的工程系统

先把这条线看清楚，后面的具体示例就会更容易读。
