# 模型扩展专题

本父目录合并了原来的 `01_slm_optimization/`、`02_multimodal_clip_search/` 和 `03_reinforcement_learning/`，目的是减少仓库顶层目录数量，同时保留各主题原本的资料结构。

## 子目录

- `01_slm_optimization/`
  - 小模型优化
- `02_multimodal_clip_search/`
  - CLIP 图像搜索
- `03_reinforcement_learning/`
  - 强化学习

## 建议学习顺序

1. 先看 `01_slm_optimization/`
2. 再看 `02_multimodal_clip_search/`
3. 最后查看 `03_reinforcement_learning/`

- 该父目录只做聚合，不拆分各子主题内部结构。
- 子目录里的命令默认以仓库根目录或各自子目录为起点，具体以子目录 README 为准。
