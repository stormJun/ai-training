操作步骤

  1. 查看算子 左侧列表展示当前已经注册到 Registry 的算子，包括数据接入、清洗和质量评估。
  2. 运行默认工作流 点击右上角“运行默认工作流”，系统会按 DAG 顺序执行 data_access -> clean -> quality_eval。
  3. 查看指标 工作流执行后，中间区域会展示接入行数、移除行数、质量分和质量门禁结果。
  4. 查看执行结果 “执行结果”区域展示完整 JSON，包括每个算子的输出、血缘信息和运行状态。
  5. 查看运行日志 “运行日志”区域展示每个节点的执行顺序和执行结果。
  6. 单算子执行 右侧选择算子后可以编辑输入 JSON 并单独执行。clean 和 quality_eval 依赖前置数据，建议先运行默认工作流。
