# RAG 与检索专题

本父目录当前收纳 `01_llamaindex_basics/`、`02_llamaindex_retrieval_basics/`、`03_ragas_retrieval_evaluation/`、`04_graphrag_basics/`、`05_local_rag_project/` 和 `06_qanything_case_study/`，目的是减少仓库顶层目录数量，同时保留各主题原本的工作区结构。

## 子目录

- `01_llamaindex_basics/`
  - LlamaIndex 基础脚本与补充笔记
- `02_llamaindex_retrieval_basics/`
  - LlamaIndex 检索基础与学习笔记
- `03_ragas_retrieval_evaluation/`
  - Ragas 检索评测与实践文档
- `04_graphrag_basics/`
  - GraphRAG 基础示例与补充资料
- `05_local_rag_project/`
  - 本地 RAG 项目与运行说明
- `06_qanything_case_study/`
  - QAnything 案例工程与前端内容

## 建议学习顺序

1. 先看 `01_llamaindex_basics/`
2. 再看 `02_llamaindex_retrieval_basics/`
3. 然后查看 `03_ragas_retrieval_evaluation/`
4. 再看 `04_graphrag_basics/`
5. 最后进入 `05_local_rag_project/` 和 `06_qanything_case_study/`

## 说明

- 该父目录只做聚合，不拆分各子主题内部结构。
- `01_llamaindex_basics/` 用来承接 LlamaIndex 的前置基础内容，便于和 `02_llamaindex_retrieval_basics/` 连续衔接。
- `05_local_rag_project/` 与 `06_qanything_case_study/` 仍然作为完整项目保留。
- 子目录里的命令默认以仓库根目录或各自子目录为起点，具体以子目录 README 为准。
