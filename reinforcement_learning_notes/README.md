## 1. 强化学习是什么

强化学习（Reinforcement Learning, RL）是一类通过“与环境交互并根据奖励信号不断调整行为”的机器学习方法。

它关注的不是“给定输入，直接预测标准答案”，而是：

- 智能体当前应该采取什么动作
- 这个动作会让未来获得更多奖励还是更少奖励
- 如何在不断试错中学到一套长期收益更高的决策策略

一句话概括：

> 强化学习研究的是“如何让智能体通过试错学习，在长期累计奖励意义下做出更优决策”。

## 2. 强化学习与监督学习的区别

监督学习通常有明确标注，例如“图片对应什么类别”“一句话对应什么情感标签”。

强化学习则不同：

- 没有现成的标准动作标签
- 反馈可能延迟出现
- 当前动作的好坏，往往要看未来一连串结果
- 需要在“探索新策略”和“利用已知策略”之间平衡

因此，强化学习比监督学习更像一个连续决策问题，而不是一次性预测问题。

## 3. 强化学习的核心组成

一个标准强化学习问题通常包含以下元素：

- **Agent（智能体）**：做决策的主体
- **Environment（环境）**：智能体交互的外部世界
- **State（状态）**：环境在某一时刻提供给智能体的信息
- **Action（动作）**：智能体在当前状态下可执行的选择
- **Reward（奖励）**：环境对动作结果给出的反馈信号
- **Policy（策略）**：智能体在不同状态下如何选动作的规则，常记为 `\pi(a|s)`
- **Trajectory（轨迹）**：状态、动作、奖励组成的时间序列

直觉上可以理解成：

环境告诉你“你现在在哪”，你选择“下一步怎么做”，环境再告诉你“这样做得到多少反馈”，你再根据这些反馈修正自己的决策方式。

## 4. MDP：强化学习的标准建模方式

很多强化学习问题可以抽象成 **Markov Decision Process, MDP**。

一个 MDP 通常写成五元组：

`(S, A, P, R, \gamma)`

其中：

- `S`：状态集合
- `A`：动作集合
- `P`：状态转移概率，即执行动作后环境如何变化
- `R`：奖励函数
- `\gamma`：折扣因子，满足 `0 \le \gamma < 1`

### 4.1 马尔可夫性质

所谓“马尔可夫”是指：

> 未来只依赖当前状态，而不依赖更久远的历史。

形式化地说：

`P(S_{t+1} | S_t, S_{t-1}, ..., S_0) = P(S_{t+1} | S_t)`

这让问题可以被简化为“当前状态足够描述决策所需信息”。

### 4.2 强化学习的目标

强化学习不是只最大化“当前一步奖励”，而是最大化长期累计回报。

定义从时刻 `t` 开始的回报（Return）：

`G_t = R_{t+1} + \gamma R_{t+2} + \gamma^2 R_{t+3} + ... = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1}`

这里的 `\gamma` 决定了智能体更看重眼前收益还是长期收益：

- `\gamma` 越小，越偏向短期
- `\gamma` 越大，越重视长期

## 5. 价值函数与贝尔曼方程

### 5.1 状态价值函数

在策略 `\pi` 下，状态价值函数表示“从状态 `s` 出发，未来平均能拿到多少回报”：

`V^\pi(s) = \mathbb{E}_\pi [G_t | S_t = s]`

### 5.2 动作价值函数

动作价值函数表示“在状态 `s` 先执行动作 `a`，之后继续按策略 `\pi` 行动时，未来平均能拿到多少回报”：

`Q^\pi(s, a) = \mathbb{E}_\pi [G_t | S_t = s, A_t = a]`

### 5.3 优势函数

优势函数用于衡量某个动作相对于该状态平均水平到底好多少：

`A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)`

如果 `A^\pi(s, a) > 0`，说明这个动作比平均动作更好。

### 5.4 贝尔曼期望方程

价值函数满足递归关系，这就是贝尔曼方程的核心思想。

对状态价值函数：

`V^\pi(s) = \sum_a \pi(a|s) \sum_{s', r} p(s', r|s, a) [r + \gamma V^\pi(s')]`

对动作价值函数：

`Q^\pi(s, a) = \sum_{s', r} p(s', r|s, a) [r + \gamma \sum_{a'} \pi(a'|s') Q^\pi(s', a')]`

这说明一个状态或动作的价值，等于“当前即时奖励 + 下一个状态未来价值”。

### 5.5 贝尔曼最优方程

最优动作价值函数满足：

`Q^*(s, a) = \sum_{s', r} p(s', r|s, a) [r + \gamma \max_{a'} Q^*(s', a')]`

这个公式是 Q-Learning 一类方法的重要理论基础。

## 6. 探索与利用

强化学习中一个经典矛盾是：

- **Exploration（探索）**：尝试没试过的动作，可能发现更优策略
- **Exploitation（利用）**：优先选择当前看起来最好的动作，稳定获得收益

如果只利用，可能陷入局部最优；如果只探索，又会学得很慢。

常见策略是 `\epsilon-greedy`：

- 以概率 `\epsilon` 随机选动作
- 以概率 `1 - \epsilon` 选择当前价值最高的动作

## 7. Q-Learning：值函数方法的代表

Q-Learning 直接学习动作价值函数 `Q(s, a)`，核心更新公式为：

`Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha [r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t)]`

其中：

- `\alpha`：学习率
- `r_{t+1}`：执行动作后获得的即时奖励
- `\gamma \max_{a'} Q(s_{t+1}, a')`：对下一状态最优未来收益的估计

方括号内这一项通常称为 **TD Error（时序差分误差）**。

### 7.1 Q-Learning 的直觉

如果某次动作带来的实际结果比当前估计更好，就把对应的 `Q` 值调高；反之就调低。

经过大量交互后，`Q(s, a)` 会逐步逼近最优动作价值函数。

### 7.2 Q-Learning 的优点

- 逻辑清晰，适合入门
- 不需要环境转移概率模型
- 在离散状态和离散动作空间下非常有效

### 7.3 Q-Learning 的局限

- 状态空间很大时，表格法难以扩展
- 连续动作空间下不方便直接取 `\max`
- 学习过程对探索策略和超参数较敏感

因此在更复杂问题中，往往需要函数逼近或策略梯度方法。

## 8. Policy Gradient：直接学习策略

### 8.1 为什么要直接学习策略

在很多任务里：

- 动作空间可能是连续的
- 策略需要天然随机性
- 只学 `Q` 值不够方便

这时可以直接对策略参数化，设策略为 `\pi_\theta(a|s)`，然后优化参数 `\theta`。

### 8.2 优化目标

策略梯度方法希望最大化策略带来的期望回报：

`J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} [R(\tau)]`

其中 `\tau` 表示一条轨迹，`R(\tau)` 表示整条轨迹的累计回报。

### 8.3 基本梯度形式

经典 REINFORCE 方法给出如下梯度形式：

`\nabla_\theta J(\theta) = \mathbb{E}_{\tau \sim \pi_\theta} \left[ \sum_t \nabla_\theta \log \pi_\theta(a_t|s_t) G_t \right]`

它的含义是：

- 如果某条轨迹最终回报高，就增加轨迹中那些动作被选中的概率
- 如果回报低，就降低这些动作被选中的概率

### 8.4 Policy Gradient 的优点

- 适合连续动作空间
- 可以直接学习随机策略
- 优化目标更贴近最终决策策略本身

### 8.5 Policy Gradient 的局限

- 梯度方差通常较大
- 样本效率往往不高
- 训练稳定性可能不如简单离散场景下的值函数方法

这也是 Actor-Critic 出现的原因之一。

## 9. Actor-Critic：策略与价值结合

Actor-Critic 把强化学习拆成两个角色：

- **Actor**：负责输出策略，决定在状态 `s` 下采取什么动作
- **Critic**：负责评估当前策略或动作有多好

### 9.1 为什么这样组合

纯 Q-Learning 偏值函数，纯 Policy Gradient 虽然直接优化策略，但方差较大。

Actor-Critic 的思路是：

- 用 Actor 保留“直接优化策略”的优点
- 用 Critic 提供更稳定的学习信号，降低梯度方差

### 9.2 TD 误差作为学习信号

一个常见的 TD 误差写法是：

`\delta_t = r_t + \gamma V_w(s_{t+1}) - V_w(s_t)`

其中：

- `V_w` 是 Critic 估计的状态价值函数
- `\delta_t` 衡量“这一步实际结果是否比原先预期更好”

### 9.3 Actor 与 Critic 的更新直觉

Actor 更新：

`\theta \leftarrow \theta + \alpha_\theta \delta_t \nabla_\theta \log \pi_\theta(a_t|s_t)`

Critic 更新：

`w \leftarrow w - \alpha_w \nabla_w \frac{1}{2} \delta_t^2`

可以这样理解：

- 如果 `\delta_t > 0`，说明这步动作比预期好，Actor 就更倾向于以后重复它
- 如果 `\delta_t < 0`，说明动作比预期差，Actor 就降低它的概率
- Critic 则不断修正自己的价值估计，使评价越来越准

### 9.4 Actor-Critic 的优点

- 比纯 REINFORCE 更稳定
- 比纯值函数法更容易处理连续动作空间
- 是很多现代强化学习算法的重要基础

常见变体包括 A2C、A3C、PPO 等。

## 10. 三类方法的直观对比

| 方法 | 核心思想 | 优点 | 局限 |
| --- | --- | --- | --- |
| Value-Based | 学习状态或动作价值，再据此选动作 | 直观、易入门、离散场景有效 | 难处理大状态空间和连续动作 |
| Policy-Based | 直接学习策略参数 | 适合连续动作，可学习随机策略 | 方差较大，训练不稳 |
| Actor-Critic | 用 Critic 评估，用 Actor 决策 | 兼顾策略优化与稳定性 | 训练细节更复杂，超参数更多 |

## 11. 强化学习的典型应用

强化学习常见于以下场景：

- **游戏 AI**：如下棋、Atari、StarCraft 决策
- **机器人控制**：机械臂抓取、行走控制、路径规划
- **推荐与广告**：长期用户价值优化
- **资源调度**：缓存、网络路由、系统资源分配
- **大模型对齐**：通过奖励模型或偏好信号优化模型行为

## 12. 强化学习与大模型训练的关系

在大模型领域，强化学习最常被提到的是 RLHF（Reinforcement Learning from Human Feedback）。

可以用一句话理解：

- 监督微调让模型“学会模仿答案”
- 强化学习让模型“朝更符合偏好的方向优化”

常见名词包括 PPO、RLHF、GRPO 等。

需要注意的是：

- 这些方法借用了强化学习思想
- 但工程实现通常比经典教科书例子复杂得多
- 像 DPO 这类方法常和 RLHF 一起讨论，但它并不是标准意义上的在线强化学习

因此，打好 MDP、价值函数、策略梯度和 Actor-Critic 的基础，理解大模型强化学习会轻松很多。

## 13. 一条实用的学习路线

如果你准备继续深入，建议按下面顺序学习：

1. 先彻底理解 MDP、回报、价值函数、贝尔曼方程
2. 再掌握 Q-Learning 和 TD Learning 的更新逻辑
3. 然后学习 Policy Gradient 和 REINFORCE
4. 接着进入 Actor-Critic、A2C、PPO
5. 最后再看 DQN、SAC、DDPG、TRPO、RLHF 等扩展主题

## 14. 总结

强化学习的核心不是“拟合答案”，而是“在交互中学会决策”。

你可以把它理解成一条主线：

- 用 MDP 建模问题
- 用回报定义长期目标
- 用价值函数估计未来收益
- 用 Q-Learning 学值
- 用 Policy Gradient 直接学策略
- 用 Actor-Critic 把两条路线结合起来

如果这条主线能讲清楚，强化学习的大部分基础框架就已经建立起来了。
